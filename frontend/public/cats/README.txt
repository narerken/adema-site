Положи сюда свои фото котов с такими именами — подключатся сами,
без правок кода (.jpg/.png/.webp — можно сменить расширение в коде,
но проще всего просто .jpg):

Главная (меняется по времени суток):
  night.jpg          - ночью (0:00-6:00), "Доброй ночи"
  morning.jpg        - утром (6:00-12:00), "Доброе утро"
  day.jpg            - днём (12:00-18:00), "Добрый день"
  evening.jpg        - вечером (18:00-24:00), "Добрый вечер"

Остальные места:
  logo.jpg           - маленький кот-логотип в шапке сайта
  login.jpg          - кот на странице входа
  surprise.jpg       - кот во всплывающем окне сюрприз-кнопки
  music.jpg          - кот на странице "Музыка"
  notes.jpg          - кот на странице "Записки"
  tasks-done.jpg      - кот, когда чек-лист дня выполнен полностью
  tasks-progress.jpg  - кот, когда чек-лист ещё не закончен

Пока файла нет для какого-то места — автоматически показывается
нарисованный кот, ничего не ломается. Можно добавлять фото
по одному, в любом порядке.
